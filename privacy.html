Privacy Policy

Mori AutoEdit · Last updated November 15, 2026

Mori AutoEdit is a private, personal tool used only by Mori to manage videos on Mori's own YouTube channel (youtube.com/@Mori). It is not offered to the public and no other users sign in to it.

What it accesses

With the channel owner's permission, the tool uses YouTube API Services to upload videos and to set titles, descriptions, thumbnails and related settings on Mori's own channel. It only accesses data belonging to that channel.

How data is used and stored

  • Data is used only to publish and manage Mori's own videos.
  • Sign-in tokens are stored only on Mori's own computers.
  • No data is sold, shared with third parties, or used for advertising.
  • No data is collected from viewers or any other YouTube users.

Revoking access

Access can be revoked at any time from the Google Account security settings at myaccount.google.com/permissions.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy can be sent through the contact form on the main page.
